Week 4 — Vorticity field: small vortices merging into big ones

2D incompressible flow · periodic [0, 2π)² · x right, y up no data

Frame format

fields.jsonl contains one JSON object per stored snapshot. t is its time, step its integer integration step, and omega an array of N² vorticity values. N is the square root of the array length. Arrays use row-major order, index iy*N + ix, at x = 2π*ix/N, y = 2π*iy/N on the periodic square. The picture has x pointing right and y pointing up.

Optional u and v arrays have the same length and layout. Together they supply the energy readout. The course gate needs all three fields; the viewer also accepts an omega-only copy. For the default run, sample every second grid point of the existing 128 × 128 recording to obtain the 64 × 64 viewer copy, keeping every timestamp.

tracers.jsonl is optional. Each line contains {"t":0.2,"x":[...],"y":[...]}, where t is a number and x and y are equally sized arrays of positions in [0,2π). Keep the same tracer order across records. The viewer draws the record nearest the field timestamp, so a tracer recording may be thinned. With one record every 0.2 time units from 0 to 10, positions match the stored field times at those 51 timestamps.

Write field values and tracer positions to 6 decimals. Drop either file onto this page, or set ?src= to the raw URL of a committed fields.jsonl. The viewer looks for tracers.jsonl beside that file. Append &t=10 to open the final frame.
